Licence 404 Errors

This License 404 error means se can not find your License for the product. A few common ways in which we can resolve this are:

  • Enable HTTP requests and API Service Intents,
  • Check your testing in Game and not Studios "Run" or "Play",
  • Check your roblox acccount that owns the game/group has a license by doing "/profile" in our discord,

If its still not working, contact us via a discord ticket!
